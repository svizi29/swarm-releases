# Swarm releases

Downloads for **Swarm**, a North Watch app: you chat with a Boss that plans the work and writes the tests, and a crew
of low-cost AI models builds it.

**Download:** [Swarm.dmg](https://github.com/svizi29/swarm-releases/releases/latest/download/Swarm.dmg),
for macOS 13 or later on Apple silicon. Needs Node.js 24 or later and your own OpenRouter key. Signed and notarized.

More at [thenorthwatch.eu/swarm](https://thenorthwatch.eu/swarm/). This repository holds release files only.
