# Swarm releases

Downloads for **Swarm**, a North Watch app for Mac and Windows: you chat with a Boss that plans the work and writes the tests, and a crew
of low-cost AI models builds it.

**Mac:** [Swarm.dmg](https://github.com/svizi29/swarm-releases/releases/latest/download/Swarm.dmg),
for macOS 13 or later on Apple silicon. Signed and notarized.

**Windows:** [Swarm-Setup.exe](https://github.com/svizi29/swarm-releases/releases/latest/download/Swarm-Setup.exe),
for Windows 10 or 11, 64-bit. Not signed yet, so Windows asks you to confirm.

Both need Node.js 24 or later and your own OpenRouter key.

More at [thenorthwatch.eu/swarm](https://thenorthwatch.eu/swarm/). This repository holds release files only.
